📍 MOSCOW/SANKT PETERSBURG ENTRY OPTIONS

Campaign: Trip 19 / Black Madonna - Chapter 5 Planning

Status: Outlaws operation - NO Delta Green handler support

Time Pressure: 2-5 days maximum preparation (NOT weeks)

Geopolitical Context: Russia 2025 = Ukraine war, extreme FSB surveillance, Western agents hunted

🚫 KRITISKA BEGRÄNSNINGAR

Vad spelarna INTE kan göra:

  • ❌ Få Delta Green handler-assistans (outlaws = ingen officiell support)
  • ❌ Använda FBI/Navy/NSA-trovärdighet (omedelbar arrestering i Ryssland 2025)
  • ❌ Begära veckor av förberedelser (brådska = dagar, inte veckor)
  • ❌ Förvänta sig evakuering om de grips (DG: "You're nobody. We can't get you back.")
  • ❌ Resa in via normalt visum (extrem FSB-övervakning + bakgrundskontroller)

Vad spelarna KAN göra:

  • ✅ Använda personliga kontakter (bonds, relationer, gamla kopplingar)
  • ✅ Utnyttja Sparkys tekniska färdigheter (24-48 timmars darkweb-åtkomst, krypterad kommunikation)
  • ✅ Använda Scalpels europeiska familjeband
  • ✅ Samla pengar för smugglingsbetalningar ($30,000-$100,000 behövs)
  • ✅ Återaktivera vilande kontakter (risk för bonds + operativ säkerhet)

🛣️ ROUTE 1: SPARKYS DARKWEB HACKER ROUTE

"Cipher's European Network"

Kontaktkedja
Sparky → Cipher
Metod
Baltic Sea Smuggling
Tid
3-4 dagar

$100-120k
Risknivå
HÖG

Hur spelarna upptäcker denna rutt:

Sparky nämner för teamet: "I know people online. Cipher's in Europe somewhere - we've never met face-to-face but we've worked together for almost a decade. Cryptography expert. If anyone knows how to move people quietly across borders..."

Utredningsväg:

  • Sparky kontaktar Cipher via krypterade kanaler (Signal, Tor-nätverket)
  • Cipher frågar: "Why do you need this? This isn't like you."
  • Sparky måste besluta: Berätta sanningen (Delta Green-operation) eller ljuga (personlig nödsituation)
  • Bond-erosionsrisk: Om Cipher upptäcker lögnen senare blir Bond skadad
  • Framgång: Cipher tillhandahåller kontakt till darkweb-marknadsplats för "diskreta resetjänster"

Ruttdetaljerna:

Metod: Baltiska havet-smuggling (Estland → Sankt Petersburg)

Logistik:

  • Kontaktpunkt: Tallinn, Estland (EU-territorium, säkrare än Ryssland)
  • Smugglartyp: Estnisk/rysk mafiya-kontakter som kör kontraband över Finska viken
  • Transport: Fiskebåt eller lastfartyg (passagerare gömda i containrar/under däck)
  • Varaktighet: 3-4 dagar (1 dag Tallinn-förberedelse, 1 dag sjöövergång, 1 dag Sankt Petersburg ankomstkoordinering)
  • Kostnad: $100,000-$120,000 totalt (för 4-5 personer)

Risker:

HÖGA RISKFAKTORER:

  • 🔴 FSB hamnpatruller - Kustbevakning aktiv i Baltikum efter Polen-incidenten
  • 🔴 Smugglarförräderi - Mafiya kan sälja spelarna till FSB ($$$)
  • 🔴 Väderförseningar - Baltiska stormar på hösten/vintern = dagar av försening
  • 🔴 Containerinspektion - Om hamninspektörer söker igenom last = omedelbar arrestering

MEDELHÖGA RISKFAKTORER:

  • 🟡 Cipher-relationen skadad - Att använda vän för farlig operation
  • 🟡 Digitalt spår - FSB övervakar darkweb-marknader (Sparkys NSA-färdigheter hjälper men inte perfekt)
  • 🟡 Ingen backup-plan - Om smugglare inte dyker upp i Tallinn, strandsatt i Estland

Bond-konsekvenser:

  • Cipher (Sparkys Bond): Potentiell erosion om operationen går fel eller Cipher lär sig hela sanningen
  • Teamkohesion: Högrisk-hasardspel på kriminella smugglare = stress

GM-noteringar:

Spelarhandlingsutrymme:

  • Låt Sparky rollspela konversation med Cipher (textbaserad, krypterad)
  • Cipher kan ställa undersökande frågor: "Are you in trouble? Is this legal? Who are these people you're traveling with?"
  • Sparky måste balansera ärlighet (bond-bevarande) vs operativ säkerhet (DG-sekretess)

Komplikationer:

  • Smugglarkontakt kan vara FSB-informant (10-15% chans)
  • Sjöövergång kan möta ryska patrullbåtar (Alertness-slag, potentiell strid)
  • Team kan bli sjösjukt, komprometterar beredskap för Moskva-operationen
