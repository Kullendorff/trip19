Nätverksintrång (Network Penetration)

Företagsnätverk / Hotell / Skolor

LÄTT Metod 1 - WiFi-Intrång

▼
  1. Koppla till WiFi (även krypterad med WPA2)
  2. Kör WiFi-handshake capture (2-5 minuter)
  3. Dictionary attack eller brute-force (10 min - 2 timmar beroende på lösenordsstyrka)
  4. Alternativt: Evil Twin attack (fake access point som loopar användare, får lösenord direkt)

Tidsfaktor: 15 minuter - 2 timmar

MEDIUM Metod 2 - Phishing

▼
  1. Skicka fake email som ser ut att komma från IT
  2. "Klicka här för att uppdatera ditt lösenord"
  3. När offret klickar: stjäl credentials eller installera malware

Tidsfaktor: 30 min att sätta upp, sedan vänta på att någon klickar (1-24 timmar)

LÄTT Metod 3 - Fysisk Access

▼
  1. Få tag på dator som är inloggad
  2. USB med BadUSB-attack (ser ut som USB-minne, agerar som tangentbord)
  3. Injicerar kod på 10 sekunder som ger dig remote access
  4. Datorn behöver inte ens vara upplåst om du använder vissa exploits

Tidsfaktor: 10 sekunder - 5 minuter

Resultat: Full tillgång till intranät, filer, kameror, emails

Reverse Engineering

▼

Statisk analys

  • Läser koden utan att köra den
  • Använder tools: IDA Pro, Ghidra, Binary Ninja
  • Kan se vad koden GÖR, vilka funktioner den anropar
  • Tidsfaktor: 1-4 timmar för medium-komplext program

Dynamisk analys

  • Kör programmet i isolerad miljö (sandbox)
  • Ser vad det faktiskt försöker göra
  • Tidsfaktor: 30 minuter - 2 timmar

Full reverse engineering

  • Återskapa source code från kompilerat program
  • Förstå EXAKT vad varje del gör
  • Tidsfaktor: Dagar till veckor för komplex software
PRAKTISKT EXEMPEL: USB-sticka
  1. Koppla INTE in den direkt (kan innehålla malware)
  2. Använd isolerad air-gapped maskin eller VM
  3. Forensic imaging först (skapa exakt kopia)
  4. Skanna för malware (20 minuter)
  5. Analysera filer (30 min - 3 timmar)

  4. Total tid: 45 minuter

UPSTREAM Collection - Fiberoptisk avlyssning

▼

NSA har direktaccess till internet backbone-kablar

Samarbetar med:

AT&T, Verizon, Level 3, andra ISPs

Ser:

ALL trafik som passerar dessa kablar

Omfattning:

~75% av amerikansk internet-trafik

Begränsning:

Kan inte se krypterad innehåll (HTTPS), bara metadata

Metadata är mer värdefullt än folk tror:
  • Vem pratade med vem, när, hur länge
  • Från vilken plats (IP-adress geolokalisering)
  • Vilken enhet (telefon vs laptop, OS-version)
  • Mönster: "Varje tisdag kl 14:00 ringer han samma nummer"

Telefonspårning & Övervakning

Cell Tower Triangulation

▼
  • Alla telefoner pingar närmaste sändarmast
  • Med 3 master kan du triangulera position till ~50-200 meter
  • Fungerar även när telefonen är i standby (måste vara påslagen)
  • NSA har access till alla stora operatörers data (AT&T, Verizon, T-Mobile)
PRAKTISKT: Var är målet just nu?
  1. Begär cell tower data för hans telefonnummer
  2. Får senaste pingen (uppdateras var 5-15:e minut)
  3. Om han rör sig: Ser rutt han färdas
  4. Om statisk: Vet att han är på specifik adress
  5. Total tid: 5-10 minuter att få realtidsdata

GPS Tracking

▼
  • Smartphones har GPS som kan aktiveras remotely
  • Precision: 5-10 meter under öppen himmel
  • Kräver: Telefonens GPS är på, eller du installerar malware som tvingar igång den
  • Batterikonsumption: Synligt för användaren om aktivt länge

Lyssna på samtal

▼
  • NSA kan aktivera microfonen i telefoner remotely
  • Fungerar även när telefonen "verkar" vara av (vissa modeller)
  • Kräver: Tidigare installerad backdoor eller zero-day exploit
  • Kvalitet: Bra vid direkt samtal, muffigt om telefonen är i ficka/väska
BEGRÄNSNINGAR
  • Om telefonen är HELT avstängd (batteri ur): Ingen spårning
  • Faraday bag: Blockerar alla signaler
  • Vissa utländska telefoner (ryska, kinesiska): Svårare att kompromitera
  • Burner phones: Om de aldrig kopplas till identitet är de anonyma tills använda

Cloud Storage (Google Drive, Dropbox, OneDrive)

▼

  • Kan ladda ner alla filer, se versionshistorik

Encrypted Cloud (Tresorit, SpiderOak)

▼
  • Zero-knowledge encryption: Företaget har inte dekrypteringsnyckeln
  • NSA kan inte läsa innehållet utan användarens lösenord/nyckel
  • Men: Kan fortfarande hacka användarens device och få nyckeln därifrån

Dark Web & Tor

Tor-nätverk

▼

"Anonymt" nätverk för dark web

  • NSA kör många exit nodes och relay nodes
  • Kan ofta de-anonymisera användare genom:
    • Traffic correlation (jämför inkommande och utgående trafik)
    • Time-based attacks (när börjar/slutar någon använda Tor)
    • Browser fingerprinting (även i Tor Browser)
Realistisk förmåga
  • Kan inte se allt på Tor, men inte helt anonymt heller
  • Om personen gör misstag (loggar in på vanligt konto via Tor): Identitet avslöjad
  • Om NSA dedikerar resurser (dagar-veckor): Kan ofta hitta användare

Dark Web Markets

▼
  • Kan övervaka vissa marknader
  • Ser transaktioner (via blockchain-analys för Bitcoin)
  • Kan infiltrera som fake sellers/buyers

Cryptocurrency Tracking

Bitcoin / Ethereum

▼
  • All transaktioner är publika på blockchain
  • Kan spåra pengar från wallet till wallet
  • Om någon växlar till fiat (riktiga pengar): Måste gå via exchange som kräver ID
  • NSA har tools för blockchain analysis

Monero / Zcash (Privacy coins)

▼
  • Designade för anonymitet
  • Mycket svårare att spåra
  • Men: Om du vet wallet-adressen kan se inkommande/utgående (mängd och tid, inte destination)
