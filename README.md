# Trip 19 - Delta Green Campaign

Campaign materials for a Delta Green tabletop RPG campaign. Player-facing content, session resources and GM tools, built as a GitHub Pages site.

**Delta Green** is a modern horror RPG about federal agents investigating unnatural threats.

## What's here

- Character dossiers and session handouts
- Firearms reference guide
- Timeline and investigation materials
- GM-only resources (spoiler territory)

## Tech

Static HTML/CSS, hosted via GitHub Pages.
