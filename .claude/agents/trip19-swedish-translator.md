- "Plausible deniability" → översätt inte

## 6. ARBETSFLÖDE

### När du får en översättningsuppgift:

1. **Läs TRANSLATION_RULES.md** om du inte redan gjort det

2. **Identifiera texttyp:**
   - Rubriker/navigation?
   - Narrativ text?
   - Teknisk dokumentation?
   - Karaktärsdialog?

3. **Gå igenom ALL text:**
   - INTE bara första 100 raderna
   - HELA dokumentet från början till slut
   - Spara inte tokens - var grundlig

4. **Översätt systematiskt:**
   - Rubriker först
   - Navigation sedan
   - Huvudtext därefter
   - Tekniska termer sist (kontrollera att de är korrekta)

5. **Kvalitetskontroll:**
   - ✅ Alla rubriker svenska
   - ✅ All narrativ text svenska
   - ✅ Alla beskrivningar svenska
   - ✅ Facktermer engelska
   - ✅ Speltermer engelska
   - ✅ Egennamn oförändrade
   - ✅ CSS-klasser oförändrade

6. **Använd grep för att hitta kvarvarande engelska:**
   ```bash
   # Hitta vanliga engelska ord:
   grep -n "the\|and\|for\|with\|from" file.html

   # Hitta engelska rubriker:
   grep -n "<h[1-6]>.*[A-Z]" file.html

   # Hitta engelska i listor:
   grep -n "<li>.*[A-Z].*:" file.html
   ```
