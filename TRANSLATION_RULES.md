# ÖVERSÄTTNINGSREGLER FÖR TRIP 19 / BLACK MADONNA

**Skapad:** 2025-11-21
**Syfte:** Standardiserade regler för översättning från engelska till svenska i alla kampanjdokument

---

## GRUNDPRINCIP

**ALL narrativ text ska vara på svenska.**
Engelska används endast för facktermer, speltermer, egennamn och tekniska termer enligt nedan.

## 2. VAD SOM SKA VARA PÅ ENGELSKA

### Speltermer (Delta Green RPG)
❌ Översätt INTE spelmekaniska termer:
- **Stats:** STR, CON, DEX, INT, POW, CHA
- **Mekanik:** HP, WP, SAN, Sanity, Bonds, Breaking Point
- **System:** Adapted to Violence, Adapted to Helplessness
- **Termer:** adaptation, SAN loss, skill check, critical success/failure
- **Egennamn:** Delta Green, The Program, MAJESTIC, Outlaws

### Facktermer - Cybersecurity & IT
❌ Översätt INTE etablerade IT-termer:
- **Protokoll:** SSH, VPN, SSL/TLS, HTTPS, FTP
- **Kryptering:** AES-256, RSA, PGP
- **System:** SIGINT, PRISM, XKEYSCORE
- **Hårdvara:** RFID, NFC, WiFi, Bluetooth, GPS
- **Mjukvara:** malware, rootkit, keylogger, backdoor
- **Nätverk:** Tor, proxy, firewall, air-gapped
- **Attacker:** Evil Twin, Relay Attack, Handshake Capture (om etablerat)

### Facktermer - Juridiskt & Myndighetsspråk
❌ Översätt INTE juridiska facktermer:
- **LEOSA** (Law Enforcement Officers Safety Act)
- **may-issue, shall-issue** (juridiska klassificeringar)
- **reciprocity** (juridisk term för ömsesidighet)
- **concealed carry** (etablerad term)
- **federal felony** (kan översättas till "federalt brott" MEN behåll i tekniska sammanhang)

### Egennamn - Organisationer
❌ Översätt INTE organisationsnamn:
- **Myndigheter:** NSA, FBI, CIA, DHS, TSA, ICE, ATF, FLETC
- **Militär:** FDNY, Navy, Marines, Army
- **Kampanj:** Delta Green, The Program, MAJESTIC
- **Fiktion:** Null Space Collective, Slava Exports

### Egennamn - Personer & Platser
❌ Översätt INTE egennamn:
- **Personer:** Kai "Sparky" Zhang, Mac Riley, Father Michael Sullivan
- **Platser:** Maryland, Virginia, Washington DC, Pennsylvania
- **Specifika:** Berwyn Heights Rod & Gun Club, Leningradsky vokzal

### Egennamn - Utrustning & Produkter
❌ Översätt INTE produktnamn:
- **Vapen:** Glock 19, SIG Sauer P365, Trijicon RMR
- **Verktyg:** Flipper Zero, HackRF One, RTL-SDR
- **Mjukvara:** Kali Linux, Metasploit, Wireshark

### Tekniska Specifikationer
❌ Översätt INTE tekniska enheter och mått:
- **Enheter:** MHz, GHz, dB, meter, yard
- **Frekvenser:** 247 Hz, 315 MHz, 433 MHz, 2.4 GHz
- **Koder:** Rolling Code, Fixed Code, KeeLoq, CAN Bus

### CSS & HTML
❌ Översätt INTE tekniska element:
- **CSS-klasser:** `.alert-danger`, `.info-box`, `.nav-link`
- **HTML-attribut:** `class`, `id`, `onclick`, `style`
- **Kod:** Alla JavaScript-funktioner och variabelnamn

## 3. SPECIALFALL & UNDANTAG

### Hybridfall - Översätt om naturligt
🔄 Vissa termer kan översättas om det blir naturligt på svenska:
- "Access" → **"Åtkomst"** (i de flesta sammanhang)
- "Device" → **"Enhet"** (när det inte är produktnamn)
- "Distance" → **"Avstånd"**
- "Setup" → **"Upplägg"**
- "Layout" → **"Planlösning"**

### Etablerade Lånord
✅ Behåll etablerade lånord som är naturliga på svenska:
- **online** (inte "på nätet")
- **cyberspace** (inte "cyberrymden")
- **email** (inte "e-post" nödvändigtvis)
- **feedback** (inte "återkoppling" nödvändigtvis)

### Sammansatta Termer
🔄 För sammansatta termer, översätt den beskrivande delen:
- "Custom **firmware**" → **"Anpassad** firmware"
- "AI-powered **protocol** detection" → **"AI-driven** protokoll**detektering**"
- "Remote control via **laptop**" → **"Fjärrkontroll** via laptop"
- "Federal **credentials database**" → "Federal credentials **databas**"

## 5. KVALITETSKONTROLL

### Innan commit, kontrollera:
1. ✅ **Alla rubriker** översatta till svenska
2. ✅ **All narrativ text** översatt till svenska
3. ✅ **Alla beskrivningar** översatta till svenska
4. ✅ **Facktermer** behållna på engelska
5. ✅ **Speltermer** behållna på engelska
6. ✅ **Egennamn** behållna på originalspråk
7. ✅ **CSS-klasser** oförändrade
8. ✅ **Tekniska specifikationer** oförändrade

### Använd grep för att hitta kvarvarande engelska:
```bash
# Hitta vanliga engelska ord som ofta missas:
grep -n "the\|and\|for\|with\|from" file.html

# Hitta engelska rubriker:
grep -n "<h[1-6]>.*[A-Z]" file.html

# Hitta engelska i listor:
grep -n "<li>.*[A-Z].*:" file.html
```
